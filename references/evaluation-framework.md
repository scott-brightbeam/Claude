# Ibec AI Programme Capstone Evaluation Framework v4.0

## Overview

This framework provides the structured methodology for evaluating capstone project submissions in the Ibec AI Programme. It assesses AI capability development across seven dimensions, each with weighted sub-criteria.

## Seven Assessment Categories

### 1. Cognitive Architecture (17.5%)
**What they delegated** - Assessment of task delegation and AI utilization

| Sub-Criterion | Weight | Description |
|---------------|--------|-------------|
| Task Complexity | 25% | Complexity of tasks delegated to AI |
| Delegation Strategy | 25% | Strategic approach to human-AI task division |
| Scope & Ambition | 25% | Breadth and ambition of the project scope |
| AI Capability Utilization | 25% | Effective use of AI capabilities |

**Scoring Calibration:**
- 5.0: Transformative complexity - 11+ document synthesis, multi-system integration
- 4.0: High complexity - significant cognitive load transferred to AI
- 3.0: Moderate complexity - standard business tasks delegated
- 2.0: Basic complexity - simple, routine tasks only
- 1.0: Minimal - trivial tasks with little cognitive delegation

### 2. Prompt Proficiency (17.5%)
**How they communicated** - Prompt engineering quality

| Sub-Criterion | Weight | Description |
|---------------|--------|-------------|
| Prompt Structure (RBSF) | 30% | Use of Role-Brief-Style-Format framework |
| Context Provision | 25% | Quality and relevance of context provided |
| Iteration & Refinement | 25% | Evidence of prompt refinement |
| Output Quality Inference | 20% | Proficiency inferred from output quality when prompts undocumented |

**Note:** When prompts are not documented, proficiency should be inferred from the quality of AI outputs.

### 3. Quality Assurance (17.5%)
**How they validated** - Verification and quality control processes

| Sub-Criterion | Weight | Description |
|---------------|--------|-------------|
| Validation Process | 30% | Systematic approach to validating AI outputs |
| Error Identification | 25% | Ability to identify and document AI errors |
| Correction & Iteration | 25% | Process for correcting identified errors |
| Human in the Loop | 20% | Application of human oversight principle |

### 4. Value Creation (17.5%)
**Business impact** - Measurable value delivered

| Sub-Criterion | Weight | Description |
|---------------|--------|-------------|
| Business Impact | 30% | Tangible business value created |
| Efficiency Gains | 25% | Time/resource savings achieved |
| Stakeholder Value | 25% | Value delivered to stakeholders |
| Sustainability | 20% | Long-term sustainability of value created |

**Scoring Calibration:**
- 5.0: Transformational impact - board-level significance, strategic value
- 4.0: Significant impact - measurable organizational benefit
- 3.0: Moderate impact - clear team/department value
- 2.0: Limited impact - minor improvements
- 1.0: No measurable impact

### 5. Reflective Practice (12.5%)
**Learning quality** - Depth of reflection and learning

| Sub-Criterion | Weight | Description |
|---------------|--------|-------------|
| Learning Depth | 35% | Depth of learning demonstrated |
| Self-Awareness | 30% | Awareness of own strengths and development areas |
| Future Application | 35% | Plans for applying learning in future |

### 6. Submission Quality (5.0%)
**Documentation completeness** - Quality of submission materials

| Sub-Criterion | Weight | Description |
|---------------|--------|-------------|
| Documentation Completeness | 35% | Completeness of required documentation |
| Clarity & Organization | 35% | Clarity and logical organization |
| Evidence Documentation | 30% | Quality of evidence provided |

**Note:** Evidence Documentation is scored separately from Prompt Proficiency.

### 7. Innovation (12.5%)
**Boundary-pushing** - Creativity and novel approaches

| Sub-Criterion | Weight | Description |
|---------------|--------|-------------|
| Novelty | 35% | Originality of approach or application |
| Boundary Pushing | 35% | Willingness to push beyond comfort zone |
| Creative Problem Solving | 30% | Creative approaches to challenges |

## Scoring Calculations

### Full Assessment Score
```
Full Assessment = (Cat1 × 0.175) + (Cat2 × 0.175) + (Cat3 × 0.175) + (Cat4 × 0.175)
                + (Cat5 × 0.125) + (Cat6 × 0.05) + (Cat7 × 0.125)
```

### Quadrant Score
The quadrant score represents core AI competency:
```
Quadrant = (Cat1 × 0.25) + (Cat2 × 0.25) + (Cat3 × 0.25) + (Cat4 × 0.25)
```

## EBIA (Evidence-Based Impact Assessment)

For each impact claim in the submission:

1. Score **Evidence Strength** (1-5):
   - 5: Quantified with verified data
   - 4: Quantified with reasonable data
   - 3: Qualitative with supporting context
   - 2: Qualitative claim only
   - 1: Unsubstantiated claim

2. Score **Impact Magnitude** (1-5):
   - 5: Transformational organizational impact
   - 4: Significant team/department impact
   - 3: Moderate process improvement
   - 2: Minor efficiency gain
   - 1: Minimal or no impact

3. Calculate Claim Score:
   ```
   Claim Score = Evidence Strength × Impact Magnitude × 4
   ```

4. Calculate EBIA Aggregate:
   ```
   EBIA Aggregate = Average of all Claim Scores
   ```

---

## Calibration Notes

Apply generous interpretation for transformative work:

- **11+ document synthesis** = transformative cognitive load (5.0)
- **Board-level presentation** = transformational value (5.0)
- **Exhaustive validation with error correction** = exceptional QA (5.0)
- **Infer prompt proficiency** from output quality when prompts undocumented
- **Evidence Documentation** is separate from Prompt Proficiency
